# Online-retail-pricing-analysis
Pricing and Revenue analysis of an Online Retail Dataset using Python and Data Analytics.
##Project Overview
This Project ananlyze an online retail dataset to identify revenue drivers, customers purchasing behaviour and pricing trends.
##Tool Used
-Python
-Pandas
-Matplotlib
-Jupyter Notebook
##Key Findings
-Highest revenue=generating category: Sports and Outdoors
-Top Selling product= Smartphones
-Most preferred payment method= Cash on Delivery
-Price and Quantity showed a very weak negative relationship
-Top revenue generating city= Port Melissaborough
##Business Recommendation
-Focus marketing efforts on sports and outdoors.
-Promote Smartphones to increase sales.
-Continue offering Cash on Delivery.
-Review pricing strategies to improve revenue.
-Target customers in Port Melissaborough.
